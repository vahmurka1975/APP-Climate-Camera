# ClimateCamera Android v1.0.11

## Изменение

Вкладка «Архив» получила локальный поиск по сохранённым копиям продуктов. Поиск учитывает название, заметки, номер слота, дату закладки и состояние записи. Данные не отправляются в сеть.

Экспорт CSV не фильтруется: он сохраняет полный архив, чтобы поиск не мог случайно скрыть данные из резервной копии.

## Проверка

Изменены только `ArchiveScreen.kt`, `app/build.gradle.kts` и `README.md`; добавлены этот файл, отчёт проверки и контрольные суммы. Полная Android/Gradle-сборка в среде подготовки не выполнена: JDK/Android SDK отсутствуют. APK v1.0.11 поэтому не заявляется.

## Как проверить в Android Studio

Выполните Gradle Sync, затем:

```text
Windows: .\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
Linux/macOS: ./gradlew :app:testDebugUnitTest :app:assembleDebug
```

После запуска откройте «Архив», введите часть названия или номера слота и убедитесь, что список фильтруется. Кнопка сохранения CSV должна экспортировать все записи, а не только найденные.
