# ClimateCamera Android v1.0.11 — исходники

Версия 1.0.10, versionCode = 12. Основа: main репозитория vahmurka1975/APP-Climate-Camera, загруженная при подготовке этого обновления; в исходной базе указана версия 1.0.9 / 10. Это исходники для Android Studio, не APK. GitHub и прошивка ESP32 не изменялись.

## Изменения

В архиве продуктов добавлен локальный поиск по названию, заметкам, номеру слота, дате закладки и состоянию. Фильтрация влияет только на отображение списка; экспорт CSV по-прежнему включает весь архив.

Капсула «Камера доступна» теперь отображается только во вкладке «Настройки». В неё перенесён текст «Данные актуальны · получены N с назад». Для ошибки, устаревших данных и остановленного обновления выводятся соответствующие честные статусы. Возраст рассчитывается по монотонным часам Android и обновляется раз в секунду.

Форма подключения также находится в «Настройках» и по-прежнему раскрывается нажатием на капсулу. На пустом главном экране кнопка «Открыть настройки подключения» переключает на эту вкладку и раскрывает форму.

Удалена общая полоска фонового чтения статуса ESP32: её появление больше не добавляет высоту в интерфейс. Повторные опросы продолжаются без изменений; полоски длительных операций в продуктах, архиве и настройках не удалялись. Первое подключение обозначается текстом, а не скачущим индикатором.

На главном экране убраны обычная строка актуальности и дублирующий текст времени ответа. Предупреждения о потере связи, устаревших значениях и остановленном обновлении сохранены, как и пометки старых показаний в карточках. Появление настоящего предупреждения может менять высоту экрана — это не индикатор регулярного опроса.

## Установка и проверка

1. Сохраните рабочий проект, ключ подписи и при необходимости экспорт архива продуктов. Не удаляйте установленное приложение и не очищайте его данные.
2. Откройте этот проект из отдельной папки в Android Studio и выполните Gradle Sync.
3. Windows PowerShell: `.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug`. Linux/macOS: `chmod +x gradlew && ./gradlew :app:testDebugUnitTest :app:assembleDebug`.
4. После успешной сборки APK находится в app/build/outputs/apk/debug/app-debug.apk. Установка поверх приложения требует того же ключа подписи.
5. Без подключения: на главном должна быть кнопка открытия настроек. Подключитесь из «Настроек»; проверьте капсулу и секундный возраст данных. На остальных трёх вкладках капсулы и формы быть не должно.
6. На главном наблюдайте несколько циклов опроса: полоски и сдвигов из-за неё нет. Отключите ESP32: предупреждение и последние значения должны оставаться видимыми. После восстановления связи предупреждение исчезает.
7. В «Настройках» нажмите «Остановить обновление»: статус не должен оставаться «Данные актуальны»; на главном отображается предупреждение.

## Перенос изменений

Архив содержит полный проект без .git и локальных секретов. Не копируйте его вслепую поверх более новой версии. UPDATE_v1.0.10.patch — альтернативный перенос кода поверх неизменённой v1.0.9: сначала `git apply --check ПУТЬ_К_PATCH`, затем `git apply ПУТЬ_К_PATCH`. Патч не переносит документацию и отчёты. Не применяйте патч повторно после копирования тех же файлов. Просмотрите diff, соберите, проверьте и только затем выполняйте Commit/Push.
