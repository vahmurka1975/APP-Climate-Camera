# Climate Camera v1.0.6

Версия: 1.0.6; versionCode: 7. Android 7.0 (API 24) и новее.
Базовый коммит: ae0e4df8930861a1b46c178ce59acee6eca7f025.
Репозиторий в ходе упаковки не изменялся; актуальность его HEAD при упаковке не проверялась.

## Изменения
- Паузы опроса при ошибках связи: 5 → 10 → 20 → 30 секунд, возврат к обычному интервалу после успешного ответа.
- Индикация восстановления соединения.
- Контрольное чтение настроек после записи: до трёх попыток, без автоматического повторения POST.
- Предупреждение о расхождении отправленных и прочитанных значений. Проверка текущих значений не доказывает сохранение в NVS.
- Подтверждение сброса несохранённых правок формы.
- Диагностика ошибок HTTPS без отключения проверки сертификатов.

## Установка
APK подписан отладочным ключом этой среды. Ключ не включён в исходники.
Установка поверх существующей версии возможна только при совпадении подписи.
При конфликте подписи предпочтительно собрать ZIP в своей Android Studio прежним ключом.
Не удаляйте рабочую версию без сохранения локальных данных и настроек.
Для последующих обновлений используйте один постоянный ключ подписи.

## Сборка исходников
Распакуйте ZIP и откройте папку ClimateCamera-v1.0.6 в Android Studio.
Укажите свой Android SDK; local.properties, кэши и локальные пути среды не включены.
Дождитесь Gradle Sync. Для проверки и сборки: ./gradlew testDebugUnitTest assembleDebug
В Windows: gradlew.bat testDebugUnitTest assembleDebug
Исходный проект использует compileSdk/targetSdk 37; соответствующий SDK должен быть установлен.

## Проверка на камере
1. Подключение, показания и обновление данных.
2. Отключение/включение Wi-Fi: устаревшие данные помечены, связь восстанавливается.
3. Изменение безопасной уставки: сверить результат с веб-интерфейсом ESP32.
4. Несохранённая правка: обновление формы запрашивает подтверждение сброса.
5. Продукты, история веса и CSV работают без регрессий.
Не проводите испытания защитных режимов на загруженной камере без безопасного плана.
