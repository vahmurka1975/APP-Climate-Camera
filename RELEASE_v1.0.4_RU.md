# Climate Camera 1.0.4 — исходники

versionName: 1.0.4; versionCode: 5. Основа: ветка main репозитория APP-Climate-Camera, скачанная 25.10.2026. Прошивка ESP32 не менялась.

## Изменения
Статус подключения и время успешного ответа. Различение DNS, тайм-аута, отказа подключения и HTTP-ошибок. После ошибки операции выполняется только повторное чтение списка, без повторного POST. Обновление списка не считается подтверждением записи. Для контрольного веса выше предыдущего добавлено подтверждение. Иконка и существующие проверки ввода сохранены из репозитория.

## Проверка
Смотрите VALIDATION_v1.0.4.json. Android-компиляция, unit-тесты и проверка на ESP32 не выполнены: Java и Android SDK в среде отсутствуют. APK не предоставляется. Не устанавливайте исходники как готовый релиз без локальной проверки.

## Применение
Сохраните незакоммиченные изменения вашей рабочей копии. Сравните файлы с этим архивом либо примените UPDATE_v1.0.4.patch из корня исходной версии проекта: сначала git apply --check UPDATE_v1.0.4.patch, затем git apply UPDATE_v1.0.4.patch. Патч рассчитан на скачанную main; при расхождении не применяйте принудительно. Не заменяйте каталог .git, local.properties и ключи подписи.

В Android Studio выполните Gradle Sync. В PowerShell из корня: .\gradlew.bat assembleDebug и .\gradlew.bat testDebugUnitTest. Поддержку SDK 37 и версий Gradle/AGP проверьте локально; существующая конфигурация сборки не менялась.

## На телефоне
Проверьте верный и неверный пароль, недоступный адрес, потерю Wi-Fi, восстановление связи, обычное взвешивание и увеличение веса с отменой/подтверждением. При сбое записи проверьте историю перед повтором. Данные сохраняются на экране в памяти только пока жив экран; нового дискового кеша в этом обновлении нет.

В архиве есть прежние отчёты VALIDATION.json и SHA256SUMS.txt из репозитория — они не относятся к проверке версии 1.0.4. GitHub и устройство автоматически не изменялись.
