# ClimateCamera v1.0.7 (versionCode 8)

## Изменения
- Фильтры продуктов: все, занятые, свободные, целевая усушка достигнута.
- Поиск точного номера слота, например 2 показывает только слот 2, а не 12/20.
- Сортировка по номеру, дате закладки, убыванию усушки, давности контрольного взвешивания.
- Сводка: занятые/свободные слоты, число достигших целевой усушки.
- Понятное сообщение, когда фильтры не нашли продукты.
- Выбор фильтра, порядка и поиск сохраняются при пересоздании экрана Android через rememberSaveable. Это не постоянные настройки профиля; при переходе в другую вкладку выбор может сброситься.
- Сортировка и фильтры локальные: дополнительных запросов к ESP32 нет, CSV по-прежнему содержит всю доступную историю активных продуктов, а не только отфильтрованный список.
- Существующие права, сохранение подключения и протокол ESP32 не изменены.
- CameraSettingsScreen.kt: только форматирование catch/finally для совместимости синтаксического анализатора, без изменения поведения.

## Установка в существующий проект
Сначала сохраните текущую рабочую версию в Git. Не удаляйте приложение на телефоне и не удаляйте .git, local.properties и ваш ключ подписи.
Распакуйте ZIP в отдельную папку. Скопируйте в ваш существующий проект только следующие файлы с сохранением путей:

1. app/build.gradle.kts
2. app/src/main/java/com/example/climatecamera/ProductsScreen.kt
3. app/src/main/java/com/example/climatecamera/ProductListPolicy.kt (новый)
4. app/src/main/java/com/example/climatecamera/CameraSettingsScreen.kt
5. app/src/test/java/com/example/climatecamera/ProductListPolicyTest.kt (новый)

Можно также скопировать RELEASE_v1.0.7_RU.md и VALIDATION_v1.0.7.json для истории.
Выполните Gradle Sync, затем в PowerShell:

    .\gradlew.bat :app:testDebugUnitTest :app:assembleDebug

Проверяйте итог BUILD SUCCESSFUL. Используйте ваш прежний ключ подписи для обновления установленного приложения.
Если подпись не совпала, не удаляйте рабочее приложение: пересоберите с прежним ключом.
